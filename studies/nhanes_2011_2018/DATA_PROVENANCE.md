# Data provenance, caching and permissions

Active final analyses use DEMO,BPX,BPQ,HUQ,HIQ,BMX,SMQ for G2011–2012,H2013–2014,I2015–2016,J2017–2018: 28 authentic XPORT files and28 source codebooks. Exact official URLs, bytes and SHA256 are in data/source_manifest.json. Downloader retries and refuses non-XPORT/non-codebook responses or changed cached content. XPORT/core codebooks for J were copied byte-identically from the original study; earlier cycles and final clinical files were downloaded directly from CDC. Preliminary unused DIQ,MCQ,DPQ caches are not final model inputs; their historical manifest is kept separately.

Data are public-use NHANES. No identifiable private records, laboratory subsample or2017–March2020 prepandemic release is introduced. Use appropriate attribution and [CDC/NCHS data-user restrictions](https://www.cdc.gov/nchs/policy/data-user-agreement.html); do not attempt identification or linkage to identified records. SEQN is public-use but participant-level derived tables are intentionally not part of the Git export.

Raw sources remain locally cached and gitignored; run `python run_all.py` to download missing sources, or `--offline` with existing caches. Source/codebooks are not bundled in the small GitHub-ready package; hashes and downloader reproduce access. Government data reuse does not assign a license to the user's new software or copyrighted articles. No Calixte PDF/Appendix is needed or redistributed; no signed URL or token is stored. The final ledger uses only verified facts from the self-contained prompt. The preserved original project is a historical working tree, not modified to scrub or relabel previous analyses.
